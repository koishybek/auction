# Что нужно от тебя, чтобы снять блокировки

Всё, что можно было сделать без тебя, сделано. Осталось три вещи, каждая
требует твоего аккаунта или пароля администратора. Порядок — по важности.

## 1. Redis — без него не поедет ядро аукциона (Phase 3)

Нативного Redis под Windows нет. Три пути, любой годится:

**Memurai** (Redis-совместимый, ставится службой; нужен пароль администратора):

```powershell
winget install --id Memurai.MemuraiDeveloper
```

Установщик уже скачан, упал только на запросе прав. После установки:

```
REDIS_URL=redis://127.0.0.1:6379
```

**Redis Cloud** (бесплатный тариф 30 МБ, регистрация ~5 минут):
[redis.io/try-free](https://redis.io/try-free) → регион `eu-central-1` →
строка подключения вида `rediss://default:ПАРОЛЬ@ХОСТ:ПОРТ` в `.env`.

**Docker Desktop** — если всё равно планировался.

Проверка после любого варианта — одна команда:

```bash
pnpm check:env
```

Она прогонит то, что пока ни разу не проверялось: `EVAL` (Lua-ядро ставки),
`PTTL` с миллисекундной точностью (таймер 50 000 мс) и pub/sub
(масштабирование WS-gateway). Если managed-тариф что-то из этого режет,
знать надо до T-024, а не во время.

## 2. GitHub-репозиторий — разблокирует CI и половину T-009

`gh` уже установлен, но не авторизован. Два шага:

```bash
gh auth login                     # браузер, твой аккаунт
gh repo create auction --private --source=. --remote=origin --push
```

После пуша сам заведётся воркфлоу `.github/workflows/ci.yml`: линтеры,
типы, юниты, **e2e на настоящих PostgreSQL и Redis в сервисных
контейнерах**, сборка образов, проверка Helm-чарта.

Отдельно в настройках репозитория: Settings → Branches → правило для `main`
с обязательными проверками `quality` и `e2e`. Только после этого DoD T-003
«PR блокируется при падении» станет правдой.

## 3. Кластер и домен — закроют T-009 полностью

Чарты написаны и валидированы (`helm lint`, `helm template`), деплой-воркфлоу
готов и ждёт двух секретов: `KUBE_CONFIG` (base64 от kubeconfig) и домена в
`infra/helm/auction/values-stage.yaml`. Подойдёт любой k8s — от k3s на VPS
до managed.
